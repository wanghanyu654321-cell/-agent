# V2.2 Evidence Selection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use inline execution with isolated-worktree verification. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Select at most one governed general-business evidence record before Pi exposure, without changing candidate retrieval or weakening Safety and governance boundaries.

**Architecture:** Preserve lexical candidate retrieval and attach its existing deterministic score/rank as optional metadata. A small product-owned selector consumes admitted general candidates, returns either one selected candidate or a fail-closed decision, and `SupportAgentRuntime` exposes/composes only that selection. Safety continues to consume raw governed candidates.

**Tech Stack:** TypeScript, Vitest, Pi 0.84.3 runtime packages, deterministic governed lexical retrieval.
