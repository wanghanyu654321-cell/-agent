# Approved Safety Knowledge

This directory is reserved for a separately reviewed, explicitly approved production safety corpus. It is intentionally empty in V1. No file elsewhere in `knowledge/safety/` becomes production evidence merely because it is Markdown or JSON.

The runtime accepts only entries whose schema status is `approved`; synthetic fixtures remain test-only and production retrieval rejects them. Until a real approved corpus is supplied and reviewed, detected professional-safety concerns pause and escalate to a qualified human.
