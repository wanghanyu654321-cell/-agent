# Public Real-World Knowledge Benchmark

This directory contains a bounded public benchmark, not a store policy or customer-production data. `approved` means approved as factual evidence for this benchmark after direct review of the cited public official source. It never means that a specific store adopted the rule.

Only the smallest atomic factual statements required by the evaluation are retained. The fetched official pages and their SHA-256 values are recorded in `docs/v2.1-retrieval/REAL_SOURCE_MANIFEST.md` and are not committed here.
